# Веб программирование
## Направления подготовки  
Курс предназначен для студентов следующих направлений подготовки:  
- Математическое обеспечение и администрирование информационных систем;  
- Информатика и вычислительная техника;  
- Программная инженерия.  

> При внесении корректировок с учётом уже усвоенного материала курс может быть адаптирован для студентов других IT-направлений.  

## Связь с другими дисциплинами  
Курс тесно связан со следующими дисциплинами:  
- Компьютерная безопасность и защита информации;  
- Основы профессионального программирования;  
- Анализ требований, тестирование и обеспечение качества программного обеспечения;  
- Разработка проектов в области компьютерных наук;  
- Операционные системы;  
- Основы управления данными;  
- Организация электронных вычислительных машин;  
- Введение в разработку веб-сайтов;  
- Современные технологии программирования;  
- Проектирование и разработка приложений для мобильных устройств;  
- Компьютерные сети и сетевая безопасность.

## Список практических работ:
Работы выполняются последовательно: каждая продолжает приложение, созданное в предыдущих. Порядок задается данным списком, директории работ названы по их теме и не содержат номеров.

1. [Знакомство с клиент-серверным взаимодействием](labs/client-server-basics)
2. [Проектирование и реализация RESTful API](labs/rest-api)
3. [Авторизация и аутентификация (JWT, OAuth2, Cookies)](labs/auth)
4. [Кеширование данных и управление сессиями с использованием Redis](labs/redis-cache)
5. [Хранение файлов с использованием MinIO (Object Storage)](labs/object-storage)
6. [Асинхронная обработка событий с использованием RabbitMQ](labs/message-broker)
7. [Знакомство с масштабированием веб-приложений на примере Kubernetes](labs/kubernetes)
8. [Разработка клиентского приложения (SPA) для взаимодействия с REST API](labs/spa-client)

> Документирование REST API с использованием OpenAPI (Swagger) не выделено в отдельную работу: базовое документирование эндпоинтов и моделей выполняется в работе [Проектирование и реализация RESTful API](labs/rest-api), схемы безопасности добавляются в работе [Авторизация и аутентификация](labs/auth).
